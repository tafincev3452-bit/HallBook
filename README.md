# HallBook

Сервис для заведений общественного питания.

## Что умеет

- Гостевая страница заведения (кто на смене, акции, меню, схема зала, бронь стола)
- Личные карточки сотрудников + QR
- Сеть скидок между заведениями
- Техкарты для поваров и барменов
- Управление сменами
- Кальянщик (отдельный режим)
- Супер-админка и админка заведения

## Стек

- Frontend: Next.js + Tailwind
- Backend: NestJS (пока не добавлен)
- База: PostgreSQL + Prisma
- Хостинг: Yandex Cloud
